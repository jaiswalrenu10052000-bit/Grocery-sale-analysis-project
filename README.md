# Grocery Sales Data Analysis Project

## Project Overview
This project focuses on analyzing grocery sales data to identify sales trends, customer purchasing behavior, product performance, and business insights.

The analysis was performed using Excel, MySQL, Python, and Power BI to transform raw sales data into meaningful business insights.

## Project Objectives
- Analyze overall grocery sales performance.
- Identify top-performing products and stores.
- Understand monthly sales trends.
- Analyze customer purchasing behavior.
- Evaluate discounts and final sales amounts.
- Create an interactive Power BI dashboard.

## Tools & Technologies
- **Microsoft Excel:** Data cleaning and data preparation.
- **MySQL:** Data storage, querying, and analysis.
- **Python:** Data analysis using Pandas, NumPy, and Matplotlib.
- **Power BI:** Interactive dashboard and data visualization.

## Dataset Information
- Total Records: 1,500
- Total Columns: 15
- Dataset Type: Grocery Sales Data

The dataset contains information about customers, stores, transaction dates, products, quantities, prices, discounts, final amounts, and loyalty points.

## Project Workflow

### 1. Excel – Data Cleaning
- Checked missing values and duplicate records.
- Reviewed data formats.
- Prepared the dataset for analysis.

### 2. MySQL – Data Analysis
- Imported the cleaned dataset into MySQL.
- Performed SQL queries for sales analysis.
- Analyzed monthly sales and customer performance.
- Used aggregate functions and grouping for business insights.

### 3. Python – Exploratory Data Analysis
- Used Pandas and NumPy for data processing.
- Analyzed sales trends and product performance.
- Used Matplotlib for data visualization.

### 4. Power BI – Dashboard Development
- Created KPI cards.
- Analyzed total sales and quantities.
- Visualized store and product performance.
- Created interactive filters and charts.
